One line, at most 200 characters: an absurd clause buried deep inside a
terms-of-service agreement. Entry for the
[Absurd Clause Contest](https://make.fun/bounty/u-donrulezz-the-absurd-clause-contest-035cc0f1)
on make.fun.

## Run

```sh
python3 main.py
```

It writes the clause to `/output/entry.txt`. Python standard library only,
no dependencies, no network.

## The clause

> Section 9.4: Any dreams you have while the app is open are licensed to us
> royalty-free and may be replayed to other users as ambient content.
